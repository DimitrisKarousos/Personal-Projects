# Overview
C++ implementations of various approximation and path finding alorithms.

## BellmanFord_SSSD
Basic implementation of the Bellman-Ford alorithm.

## BellmanFord_SSSD_verify
Varification and testbench for the above.

## FastSwap
Comparison of a faster way to swap integers and the traditional temporary variable approach.

## Gradient Descent
Incomplete implementaion of the gradient descent algorithm.

## NewtonRaphsonApproximation
Basic implementation of the Newton-Raphson algorithm.

## PolynomialBisection
Incomplete implementation of the Polynomial Bisection algorithm.

## PolynomialGradientDescent
Incomplete implementation of the Polynomial Gradient Descent alorithm

## RegulaFalsiApproximation
Incomplete implementaion of the Regula Falsi algorithm.

## VectorMath
Basic implementation of the fundamental vector and matrix processes.
