# Overview
A collection of approaches in solving the bin-packing problem.

## BestFit
Implementation of the Best Fit algorithm.

## FirstFit
Implementation of the First Fit algorithm.

## WorstFit
Implementation of the Worst Fit algorithm.

## FFDecreasing
Implementation of the First Fit Decreasing algorithm.

## Refined FF
Implementation of the Refined First Fit algorithm.

## MFFD
Implementation of the Modified First Fit Decreasing algorithm.

## MBF
Implementation of a custom 'Modified Best Fit' algorithm.

## MWF
Implementation of a custom 'Modified Worst Fit' algorithm.

## MRFF
Implementation of a custom 'Modified Refined First Fit' algorithm.

## FF_PTAS
Implementation of a Polynomial Time Aproxximation Scheme based on the First Fit algorithm.

## BF_PTAS
Implementation of a Polynomial Time Aproxximation Scheme based on the Best Fit algorithm.

## BinPacking
Naive approach to solving the Bin Packing problem, focusing on high accuracy.

## VarBagVolBP
Naive algorithm based on the previous, accounting for bags of variable sizes.
