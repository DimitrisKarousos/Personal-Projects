# Overview
Basic Python simulations of various systems.

### LFSR
Basic simulation of a Linear-feedback shift register.

## Bin Packing
Contains implementations of various algorithms, simulating the solution to the bin-packing problem.

## Strip Packing
Contains implementations of various algorithms, simulating the solution to the strip-packing problem.

## Tetris
Contains impementations of various algorithm,s simulating the solution to a tetris game, in both 2D and 3D contexts.
