# Overview
A collection of approaches to solving a tetris game based on approaches from Pierre Dellacherie.

## GridInit
Auxilliary script that initiallizes an empty grid.

## FindCol
Auxilliary script that checks for possible moves.

## DellacherieFeatures
Auxxiliary script that caluclates certain game features as describe by Dellacherie.

## Dellacherie2D
Implementation of Dellacherie's algorithm on a classical tetris game.

## Dellacherie3D
Implementation of Dellacherie's algorithm in a 3D context.

## Dellacherie2D3DMerge
Implementation calculating features using information from the 3rd axis.
