#This directory contains Unity scripts I frequently use when creating games.

##Cube.cs & Background Rotator.cs:
These scripts create an abstract animated 3D background in Unity.
Suitable for 2D games.

###To Use:
Create a set of 3d objects (cubes, spheres, etc), setting them to kinematic.
Add the Cube.cs script to all of them.
Create an empty game object and parent it to all objects in the set.
Add the Background Rotator.cs script to that object.
